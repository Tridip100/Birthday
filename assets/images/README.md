# Your photos go here

For the memories chapter, add six photos for each year in this structure:

- `memories/2019/01.jpg` through `06.jpg`
- `memories/2020/01.jpg` through `06.jpg`
- Continue for every year you want shown (the starter configuration contains 2019–2026).

The starter folders for 2019–2026 are already here. Change the year list in `../js/content.js` if you need different years.

The old four-photo setup can be ignored.

- `memory-01.jpg`
- `memory-02.jpg`
- `memory-03.jpg`
- `memory-04.jpg`

You can use `.png` or `.webp` instead, but then update the matching `image` value in `../js/content.js`.
