# Year-by-year memory photos

The 2019–2026 folders are already prepared; add six photos in each folder:

```text
memories/
  2019/01.jpg ... 06.jpg
  2020/01.jpg ... 06.jpg
  2021/01.jpg ... 06.jpg
  ...
```

The starter page contains 2019 through 2026. Update `assets/js/content.js` if you want different years. Missing images show a pink placeholder, so you can add the photos gradually.
